# Screenshots

Every image here is rendered from this project by `tools/screenshots.sh`
(the mod's own renderer, through `tools/preview.ts` and
`tools/render_shot.py`), with no terminal and no Claude session.

## Names

| File | Shows |
| --- | --- |
| `scene-<theme>.png` | a theme's scene with its HUD (`scene-river-rpg.png` is the README's hero) |
| `state-<state>.png` | the default theme in one session state: `thinking`, `tool`, `waiting`, `done`, `error`, `compacting` |
| `hud.png` | the HUD close up |

New images follow the same pattern: lowercase, hyphenated, `.png`.

## Rules

- **Only images rendered from this project.** No captures of other games or
  apps, no third-party art, no reference pictures.
- **Privacy.** The numbers in the status window are made-up demo figures.
  A real screenshot added by hand must show no real project name, path,
  user name, e-mail, cost, session or account data: crop to the pane, and
  use a mock project (`~/projects/my-app`, user `you`).
